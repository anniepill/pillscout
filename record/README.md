# The record

ingredients/records/ginkgo.yaml is the full ginkgo record from the private corpus with its authoring machinery removed for publication: the citation_gaps and version_history blocks are emptied, the derived word-position index is stripped, the internal ticket references in notes are reworded, and one free-text field that told a reading model how to weigh a claim is deleted, because the corpus states and does not interpret. No quote and no label was changed.

The validator, schema and tests sit beside it. The run commands are in the top-level README.
